# dodge blobs

`blobs/` and the `overlays/` APKs are generated by `extract-files.py` from stock CPH2649_11.H.05 and committed.
OplusCamera.apk, OppoGallery2.apk, AIUnit.apk, VideoGallery.apk and the arcsoft libs are stored with Git LFS.

Install git-lfs before syncing (`repo init ... --git-lfs`, or `git lfs pull` in this repo).
Without it the APKs are small pointer files and the build fails.

To regenerate, run `./extract-files.py --allow-prohibited-files <dump>`; the dump needs `my_product` and `my_stock`.
